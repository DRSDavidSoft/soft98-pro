# Related posts and useful-software artwork

Soft98 Pro displays the artwork already published in the linked Soft98 post. It
does not bundle product artwork. Related posts load artwork as their rows come
into view. The useful-software list does the same when opened from the header,
including for extra rows as they are expanded or scrolled into view.

Requests are limited to same-origin post URLs. Soft98 Pro reads the artwork
metadata without running the fetched page, caches the result in the browser,
and spaces requests out, including waiting when Soft98 asks clients to retry
later. Rows without usable artwork retain a neutral glyph. Category links
never borrow artwork from one of their results.
