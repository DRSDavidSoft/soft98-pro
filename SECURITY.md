# Security Policy

## Supported versions

Security fixes are provided for the latest published Soft98 Pro release.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/DRSDavidSoft/soft98-pro/security/advisories/new). Do not publish exploit details in a public issue.

Include the affected browser, Soft98 Pro version, reproduction steps, impact, and a minimal proof of concept. You should receive an acknowledgement within seven days. Release timing depends on severity and coordinated disclosure needs.

Soft98 Pro never needs account credentials, authentication cookies, or private browsing data for a security report.
