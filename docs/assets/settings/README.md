# Settings previews

These before/after images come from the live AnyDesk page in an unsigned-in Firefox profile. The RGB loop uses real browser captures at evenly spaced points in the site's RGB cycle. Reduced-motion mode uses a single captured frame instead.

Dark mode, latest posts, the site logo, and RGB use real Soft98 captures. The remaining options use labeled illustrations where a screenshot would show little more than a switch changing state. The artwork is generated by `tools/preview-illustrations.js`. The source choice is in `src/option-previews.json` and is shared by Settings and the in-page control center.

Set `SOFT98_CONTROL_PREVIEWS` to a temporary output directory and run `node tools/firefox-live-smoke.js` with the local Firefox WebDriver and the latest built Firefox package. Crop the captures to 16:9 and resize to 460 pixels wide for these WebP assets. The expanding-article pair uses a centered crop; the remaining pairs use a top-aligned crop. Encode the RGB sequence in filename order with a 320 ms frame duration and a continuous loop.

The [comparison gallery](../comparison/README.md) uses the same preview catalog and documents all Control Center switches. After changing a switch or its preview, run `npm run docs:comparison`.

For the full-page pair, set `SOFT98_COMPARISON_DIR` to a temporary directory and run the Firefox smoke script twice: once with `SOFT98_BASELINE=1` (no add-ons), then again without it (Soft98 Pro extension only). The script verifies both states before capture. Use `downloads-before.png` from the first run and `downloads-after.png` from the second as the gallery baseline and `docs/assets/soft98-pro-dark.png`, respectively.

Set `SOFT98_COMPARISON_FEATURES=1` during the extension run to also capture the gallery's additional visible switches, or set it to one setting key. Resize the matched pairs to 960 px wide without cropping and save them as WebP in `docs/assets/comparison/live/`. The animated RGB and smaller previews stay in this settings directory.
