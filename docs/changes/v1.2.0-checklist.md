# Soft98 Pro 1.2.0 checklist

This is the acceptance record for the redesign in PR #4. The release is on hold pending approval. See the [visual changelog](v1.2.0.md) for screenshots; the entries below also distinguish behavior tests from screenshots.

| Area | Coverage and current boundary |
| --- | --- |
| Ultrawide and mobile layout | Live Firefox at 3840, 1440 and 500 px. On the ultrawide AnyDesk page, the content frame measured 2170 px without horizontal overflow. Optional scroll widening grew with scrolling and kept the sidebar on the same side. Empty columns reclaim their space, and the utility card can be restored to the sidebar. |
| Header, cards, and FAQ | The acrylic megamenu, sticky actions, shared article title/metadata treatment, muted news counters, and FAQ transitions are implemented. The Windows 11 live check found six styled Read more controls and no empty ad heading or orphaned outer divider. The feedback page did not show the floating support image. |
| Download area | Firefox showed all six AnyDesk rows, restored them after switching tabs or hiding the list wrapper, and downloaded the original ZIP. The browser fixture checks group collapse, copying public links, password selection, and toast expiry. |
| Download queue | A separate native Firefox test verified parallel transfers, byte progress, pause/resume, queue reload, a relative save path, and exact fixture bytes. The browser owns absolute save locations. The userscript cannot use the extension-only queue API. |
| Listing previews and Quick Browsing | Quick Browsing is opt-in for supported software listings and pagination; Firefox verified Next, Back, and Forward without a full reload. Other pages, forms and downloads retain normal navigation. Listing previews show public file links and open the site's download tab for site-managed links. They do not guess direct URLs. |
| Control center | Browser tests cover persistent position, magnetic docking, drag-to-hide, menu bounds, keyboard actions, report, and scroll stability when options change. RGB gradients preserve reduced motion. The bundled [setting comparisons](../assets/settings/README.md) use real captures; not every switch has a separate image. |
| Utility artwork and search | The expanded card has a catalog of 23 destinations, with verified artwork or distinct artwork where appropriate. Some entries are category pages and some have no verified artwork reuse grant; these intentionally keep category icons or clearly identified tiles. F2 focus was verified live. Known search thumbnails use bundled icons; arbitrary upstream thumbnails are not recolored. |
| Themes, overlays and comments | The stock night toggle and Pro stay in sync. The utility dialog follows the URL and Back button in live Firefox; the download notice and recognized read-only dialogs also have hash handling. Forms and unrelated third-party overlays are not taken over. Comment layout and reply controls have live captures; submission is tested with a fixture, not a public post. |
| Footer and inspection | The footer has solid theme surfaces, Pro attribution, settings and project links, with desktop and narrow captures. The green accent is replaced where recognized. Inspect rendered elements with the `data-soft98-pro-*` attributes or `Soft98Pro.inspectedRoles()`; the site’s original class names are intentionally kept so its CSS and event handlers keep working. |

Release notes explain the observed site-managed download behavior without attributing motives or authorship. Release publication and final human review remain open.
